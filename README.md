# سنگ کاغذ قیچی ایرانی 🇮🇷

بازی سنتی سنگ کاغذ قیچی با تم ایرانی و گرافیک دوبعدی، طراحی شده برای Android Studio (Kotlin + XML).

## ✨ ویژگی‌ها

- **منوی اصلی** با سه گزینه: شروع بازی، فروشگاه و خروج
- **سه حالت دست با انیمیشن**: سنگ (مشت ✊)، کاغذ (دست باز ✋)، قیچی (دو انگشت ✌)
- **۸ اسکین متنوع** برای دست‌ها در فروشگاه:
  - دست پایه (رایگان)
  - تتو گل (۲۰۰ سکه)
  - تتو ایران (۵۰۰ سکه)
  - دست طلایی (۱۰۰۰ سکه)
  - دست آتشین (۸۰۰ سکه)
  - دست زمردی (۶۰۰ سکه)
  - تتو شیر هخامنشی (۷۰۰ سکه)
  - دست پادشاهی (۱۰۰۰ سکه)
- **سیستم اقتصادی**: شروع با ۱۰۰۰ سکه، ۵۰ سکه برای هر برد، ۵ سکه برای مساوی
- **هوش مصنوعی هوشمند**: حریف الگوهای بازیکن را یاد می‌گیرد و بهترین حرکت را انتخاب می‌کند (حدود ۶۰٪ سختی)
- **تم سنتی ایرانی**: پس‌زمینه تخت جمشید به سبک Vector Drawable با پالت خاکی و سنگی
- **افکت‌های صوتی کامل**: کلیک، شمارش، برد، باخت، مساوی، سکه، خرید و انتخاب
- **موسیقی پس‌زمینه محلی**: ملودی آرام با تم مقام ایرانی
- **انیمیشن‌های نرم**: مچ زدن دست، شمارش معکوس، رونمایی با افکت bounce و pop
- **ذخیره خودکار**: پول، اسکین‌های خریداری‌شده و آمار بازی در SharedPreferences ذخیره می‌شوند
- **پشتیبانی از فارسی RTL**: تمام رابط کاربری راست‌چین و با فونت Vazirmatn

## 🚀 نصب و اجرا در Android Studio

### پیش‌نیازها
- Android Studio Hedgehog (2023.1.1) یا بالاتر
- JDK 17 (به‌صورت پیش‌فرض همراه Android Studio نصب می‌شود)
- Android SDK 34 (Compile SDK) و Android 7.0 (API 24) به حداقل

### مراحل

1. **کپی پروژه**: فایل ZIP دانلودی را در یک مسیر دلخواه استخراج کنید.

2. **باز کردن پروژه**:
   - Android Studio را باز کنید
   - **File → Open** را انتخاب کنید
   - به مسیر پوشه `RockPaperScissorsIR` بروید و آن را انتخاب کنید
   - روی **OK** کلیک کنید

3. **تنظیم SDK**:
   - اگر خطای SDK خوردید: **File → Project Structure → SDK Location**
   - مسیر Android SDK سیستم خود را وارد کنید (معمولاً `~/Library/Android/sdk` در مک، `~/Android/Sdk` در لینوکس)
   - فایل `local.properties` را با مسیر صحیح SDK خود ویرایش کنید:
     ```
     sdk.dir=/path/to/your/Android/Sdk
     ```

4. **Gradle Sync**: پس از باز شدن پروژه، Gradle به‌طور خودکار همگام‌سازی می‌شود. اگر نشد:
   - **File → Sync Project with Gradle Files**
   - اندروید استودیو Gradle wrapper را به‌صورت خودکار دانلود می‌کند (نسخه 8.3)

5. **اجرا**:
   - یک دستگاه یا شبیه‌ساز (Emulator) با API 24 یا بالاتر آماده کنید
   - روی دکمه **Run** (سبز ▶) در نوار ابزار کلیک کنید
   - یا میانبر `Shift + F10` را بزنید

### رفع مشکلات احتمالی

- **خطای "Plugin with id 'com.android.application' not found"**: مطمئن شوید پروژه را با Android Studio باز کرده‌اید، نه فقط فایل‌های منبع.
- **خطای "SDK location not found"**: فایل `local.properties` را با مسیر SDK خود ویرایش کنید.
- **خطای font**: اگر فونت‌ها یافت نشدند، مطمئن شوید پوشه `app/src/main/res/font/` حاوی فایل‌های `vazirmatn_*.ttf` است.
- **شکست در build Gradle**: **Build → Clean Project** سپس **Build → Rebuild Project** را اجرا کنید.

## 🎮 نحوه بازی

1. در منوی اصلی روی **شروع بازی** بزنید
2. دست خود را انتخاب کنید: **سنگ**، **کاغذ** یا **قیچی**
3. هر دو دست با انیمیشن مچ زدن شروع به تکان خوردن می‌کنند
4. شمارش معکوس: ۳ → ۲ → ۱
5. دست‌ها نمایش داده می‌شوند و برنده مشخص می‌شود:
   - سنگ → قیچی را خرد می‌کند
   - کاغذ → سنگ را می‌پوشاند
   - قیچی → کاغذ را می‌برد
6. در هر برد **۵۰ سکه** دریافت می‌کنید
7. با سکه‌ها می‌توانید از **فروشگاه** اسکین‌های متنوع بخرید

## 🛒 فروشگاه

- ۸ اسکین متنوع در دسترس
- هر اسکین می‌تواند رنگ، تتو و افکت خاص خود را داشته باشد (هاله طلایی، آتش، زمردی، پادشاهی)
- پس از خرید، اسکین به‌صورت خودکار انتخاب می‌شود
- می‌توانید بین اسکین‌های خریداری‌شده جابجا شوید

## 🧠 هوش مصنوعی حریف

حریف کامپیوتری از یک استراتژی ساده اما مؤثر استفاده می‌کند:
- **۳۰٪ مواقع** کاملاً تصادفی حرکت می‌کند (برای غیرقابل پیش‌بینی بودن)
- **۷۰٪ مواقع** بر اساس ۱۰ حرکت اخیر بازیکن، حرکتی را پیش‌بینی کرده و ضدحرکت می‌کند
- اگر بازیکن ۳ بار متحرک یکسان انجام دهد، احتمال تکرار آن را در نظر می‌گیرد

## 🔧 سفارشی‌سازی

### افزودن اسکین جدید

فایل `HandSkin.kt` را باز کنید و یک مقدار جدید به enum اضافه کنید:

```kotlin
NEW_SKIN(
    id = 8,
    nameResId = R.string.skin_new,
    price = 500,
    baseColor = 0xFFFF00FF.toInt(),
    shadowColor = 0xFF880088.toInt(),
    nailColor = 0xFFFFFFFF.toInt(),
    tattooType = TattooType.FLOWER,
    effectType = EffectType.GOLD_GLOW
)
```

سپس نام فارسی آن را به `strings.xml` اضافه کنید:
```xml
<string name="skin_new">اسکین جدید</string>
```

### تغییر رنگ پس‌زمینه

فایل `bg_persepolis.xml` در پوشه `drawable/` را ویرایش کنید. این یک Vector Drawable است که می‌توانید مسیرها و رنگ‌های آن را سفارشی کنید.

### تنظیم صدای پس‌زمینه

فایل `bg_music.ogg` در پوشه `res/raw/` را با موسیقی مورد نظر خود جایگزین کنید. فرمت OGG توصیه می‌شود.
